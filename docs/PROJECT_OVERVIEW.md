# 项目概览：这个项目能干什么

DB Sentinel Agent 是一个面向业务数据分析值班场景的只读数据库 Agent Demo。它的目标不是替代完整 BI 系统，而是把业务同学最常见的临时问数流程做成一个安全、可解释、可审计的 Web 工作台。

![DB Sentinel Agent 系统总览](assets/system-overview.svg)
![工作台查询结果截图](assets/screenshots/gmv-result.png)

## 一句话理解

业务同学用自然语言提问，Agent 自动理解示例数据库、生成只读 SQL、先做安全校验、再执行查询，最后给出表格、图表、业务解释和审计轨迹。

## 它适合解决什么问题

| 场景 | 用户会问 | Agent 会做什么 |
| --- | --- | --- |
| 渠道经营复盘 | 最近 7 天 GMV 最高的渠道是什么？ | 查 paid 订单，按渠道汇总 GMV 和订单数，返回排名、图表和解释。 |
| 增长异常定位 | 哪个渠道转化率下降最多，可能原因是什么？ | 对比最近 7 天和前 7 天访问量、订单量、转化率，找下降最大渠道。 |
| 活动投放复盘 | 618 活动期间 ROI 最好的渠道是哪几个？ | 结合活动预算和活动期订单 GMV，计算渠道 ROI。 |
| 售后风险发现 | 找出最近一周退款率异常升高的商品类别。 | 按商品类别对比两周退款率，找异常升高项。 |
| 新用户分析 | 新用户首单转化在不同城市有什么差异？ | 统计新注册用户 7 天内首单转化率，并按城市排序。 |
| 安全验证 | 帮我 drop table orders | 拦截危险 SQL，不执行数据库操作，展示安全原因。 |

## 当前能做的事

- 展示数据库 schema、字段说明、样例值和表行数。
- 支持 5 个业务分析样例问题。
- 自动生成查询计划和 SQL。
- 用 SQL guard 校验查询是否只读。
- 执行安全查询并返回结构化结果。
- 自动生成 Recharts 图表。
- 给出业务解释、数据限制和下一步建议。
- 保留每次会话的审计记录。
- 未配置 LLM key 时仍可稳定演示。
- 用 `config/app.conf` 统一管理 URL、API、端口和数据库路径。

## 当前不能做的事

- 不能直接连接生产数据库。
- 不能执行写操作或数据修复操作。
- 不能保证回答任意开放式自然语言问题。
- 不能替代指标平台、权限系统、数据血缘或数据治理平台。
- 当前审计记录保存在进程内存里，服务重启后会丢失。
- 不是 CC / Hermes 级别的通用 agent 平台；它是垂直 Agent 应用。

这些限制是刻意设计的。Hackathon Demo 优先证明“只读、安全、可审计的数据分析 Agent 工作流”成立，而不是冒险连接真实生产数据。

## 数据库里有什么

内置 SQLite 示例库包含 6 张表：

- `users`：用户城市、分层、注册日期。
- `channels`：渠道名称和类型。
- `products`：商品类别和价格。
- `orders`：订单金额、渠道、商品、时间和状态。
- `campaigns`：618 活动周期、预算和渠道。
- `events`：访问和购买事件，用于计算渠道转化率。

种子数据覆盖了可演示的业务现象：

- Douyin Ads 最近 7 天 GMV 较高。
- Xiaohongshu 最近 7 天流量增加但转化下降。
- 不同渠道活动预算不同，可比较 ROI。
- Smart Home 最近一周退款率明显升高。
- 不同城市新用户首单转化率存在差异。

## 为什么它不是普通 NL2SQL

普通 NL2SQL 的核心是“把一句话翻译成 SQL”。DB Sentinel Agent 的核心是“把问数流程做成可审计工作流”：

- 查询前：展示 schema 理解和分析计划。
- 查询中：展示 SQL 和只读安全校验。
- 查询后：展示表格、图表、解释和下一步建议。
- 出问题：危险 SQL 被拦截，并保留原因。

这更接近企业里真正可用的数据分析 Agent。

## 典型用户路径

1. 业务同学打开工作台。
2. 查看左侧 schema 和样例问题。
3. 点击或输入一个数据问题。
4. 中间区域看到 Agent 的计划、SQL 和解释。
5. 右侧看到图表、表格和审计轨迹。
6. 如果问题涉及危险写操作，系统直接拦截。

![危险请求拦截图](assets/screenshots/safety-block.png)

## 成功标准

这个 Demo 成功的标准不是“模型多聪明”，而是评审可以亲手确认：

- 它能回答业务问题。
- 它能展示 SQL 和结果。
- 它能解释为什么得出这个结论。
- 它能拦截危险操作。
- 它能保留完整审计轨迹。
- 上传后评审能从 `config/app.conf`、页面顶部和 `/api/config` 确认 URL/API 配置。
